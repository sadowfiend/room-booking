# Manual QA — фаза 4

Чек-лист по PLAN.md (фаза 4). Для каждого сценария: что делать, что ожидать, какие автотесты его покрывают
и что уже прогнано. Столбец «Вручную» заполняет человек.

## Окружение

- Локально: `npm run build && MOCK_ALLOW_FORCED_CONFLICT=1 NEXT_PUBLIC_DEV_TOOLS=1 npm run start`
  (`NEXT_PUBLIC_*` подставляется при сборке — для переключателя 409 задайте её и перед `build`).
- Хранилище: `GET /api/health` → `storage: "memory"` без env Redis, `"redis"` с env (список имён — PLAN.md, 3C).
- Тестовая дата для API-прогона: `2026-10-20` (будущая); прошедшая — `2026-10-01`.

## Прогон API (2026-10-07, `next start`, in-memory, `MOCK_ALLOW_FORCED_CONFLICT=1`)

Запросы `curl` к собранному приложению. Все результаты совпали с ожидаемыми.

| Проверка | Запрос | Результат |
|---|---|---|
| Хранилище | `GET /api/health` | 200 `{ ok: true, storage: "memory" }` |
| Создание, `title` с пробелами | `POST` 10:00–11:00, `" Планёрка "` | 201, `title: "Планёрка"` |
| Касание границ | `POST` 11:00–12:00 | 201 |
| Пересечение | `POST` 10:30–11:30 | 409, `conflicts` = бронь 10:00–11:00 |
| Вложенный интервал | `POST` 10:15–10:45 | 409 |
| Форсированный 409 | `POST` 15:00–16:00 + `x-mock-force-conflict: 1` | 409, `conflicts: []` |
| Редактирование без самоконфликта | `PATCH` 10:00–11:00 → 09:45–11:00 | 200 |
| Редактирование в соседа | `PATCH` → 10:00–11:15 | 409, `conflicts` = бронь 11:00–12:00 |
| Шаг 15 мин | `POST` 13:15–14:00 | 201 |
| Не по шагу | `POST` 13:10–14:00 | 422 `OFF_STEP` (start) |
| Больше 2 ч | `POST` 14:00–16:30 | 422 `TOO_LONG` |
| Вне рабочего дня | `POST` 17:30–18:30 | 422 `OUTSIDE_WORKING_HOURS` |
| Прошедшая дата | `POST` 2026-10-01 | 422 `PAST_DATE` |
| Битый JSON | `POST` `{bad` | 400 `BAD_REQUEST` |
| Мусор в теле | `POST` `[1,2]` | 422 `INVALID_BODY` |
| Список | `GET ?date=2026-10-20` | 200, отсортирован по `start` |
| Несуществующая дата | `GET ?date=2026-02-30` | 422 `INVALID_DATE` |
| Удаление | `DELETE` | 204 |
| Повторное удаление («другая вкладка») | `DELETE` того же id | 404 `NOT_FOUND` |
| Редактирование удалённой | `PATCH` того же id | 404 |
| Свежесть | заголовки `GET` | `Cache-Control: no-store` |
| Гонка (in-memory) | 10 параллельных `POST` 16:00–17:00 | 1 × 201, 9 × 409 |
| Страница | `GET /` | 200 |

Наблюдение: `PATCH` — полное тело (PLAN.md), поэтому запрос без `title` убирает название. Форма всегда
отправляет `title`, это поведение по контракту, а не ошибка.
